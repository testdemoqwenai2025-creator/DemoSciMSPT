## 🆘 **Troubleshooting**

### **Issue: "Page Not Found" (404)**
**Cause:** GitHub Pages not enabled yet  
**Fix:** 
1. Go to repository Settings → Pages
2. Source: Deploy from branch → `main` → `/ (root)`
3. Save — site goes live in 2-3 minutes

### **Issue: "Site shows old version"**
**Cause:** CDN cache or browser cache  
**Fix:**
- Hard refresh: `Ctrl+Shift+R` (Windows/Linux) / `Cmd+Shift+R` (Mac)
- Wait 5-10 minutes for CDN propagation
- Try incognito/private browsing mode

### **Issue: "Styles not loading correctly"**
**Cause:** Jekyll processing removing files  
**Fix:** `.nojekyll` file present (already included) — should resolve automatically

### **Issue: "Workflow failed"**
**Check:**
1. Go to Actions tab → Click failed run → View logs
2. Common fixes:
   - Syntax error in YAML file
   - Missing files referenced in workflow
   - Permission issues (re-check repository settings)
